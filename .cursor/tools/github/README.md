# @modelcontextprotocol/server-github

A Node.js server library for integrating GitHub as a context provider using the [Model Context Protocol](https://modelcontext.org/). This package allows you to connect, fetch, and manage GitHub repositories, issues, pull requests, and more, exposing them as context for your applications.

## Features

- Connect to GitHub using OAuth or Personal Access Tokens
- Fetch repositories, issues, pull requests, and files
- Webhook support for real-time updates
- Expose GitHub data as context for LLMs and other applications
- Easy integration with [@modelcontextprotocol/server](https://www.npmjs.com/package/@modelcontextprotocol/server)
