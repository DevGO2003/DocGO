# Architecture Documentation

Thư mục này chứa các tài liệu liên quan đến kiến trúc dự án DocGO.

## Nội dung

- **DocGO - Sơ đồ Kiến trúc hệ thống.drawio**: Sơ đồ kiến trúc tổng thể của hệ thống DocGO
- **DocGO - Mô tả kiến trúc dự án.xlsx**: Mô tả chi tiết về kiến trúc và thiết kế dự án

## Mục đích

Các tài liệu này giúp developers và stakeholders hiểu rõ:
- Cấu trúc tổng thể của hệ thống
- Luồng dữ liệu giữa các microservices
- Thiết kế database và API
- Quyết định kiến trúc quan trọng
