# Prompt 01: Quan sát cấu trúc và chuẩn bị triển khai

## Mục tiêu
Quan sát cấu trúc hiện tại của dự án DocGO và chuẩn bị triển khai kiến trúc mới với 4 microservices.

## Nhánh hiện tại: dev

## Yêu cầu thực hiện

### 1. Quan sát cấu trúc hiện tại
- Liệt kê tất cả microservices hiện có trong thư mục `backend/`
- Phân tích cấu trúc thư mục và file của từng service
- Xác định công nghệ sử dụng (Spring Boot, FastAPI, Next.js)
- Kiểm tra file `docker-compose.yml` để hiểu cách services được orchestrate

### 2. Phân tích kiến trúc mới (4 microservices)
- **api-gateway** (Next.js): Port 8000 - API Gateway và BFF
- **user-management-service** (Spring Boot): Port 8001 - Quản lý user, auth, organization
- **document-management-service** (Spring Boot): Port 8002 - Quản lý contracts, files, documents
- **ai-service** (FastAPI): Port 8003 - AI processing, OCR, analytics
- **web-app** (Next.js): Port 3000 - Frontend application

### 3. Lập kế hoạch migration
- Xác định services nào cần được gộp lại
- Lập danh sách các file cần di chuyển
- Xác định dependencies và configurations cần cập nhật
- Lập timeline triển khai từng bước

### 4. Chuẩn bị môi trường
- Kiểm tra Docker và Docker Compose
- Xác định các biến môi trường cần thiết
- Chuẩn bị database schemas và migrations
- Kiểm tra network và port configurations

## Lưu ý quan trọng
- **Làm việc trên nhánh `dev`**
- **Không xóa hoặc thay đổi code hiện tại** - chỉ quan sát và phân tích
- **Tạo báo cáo chi tiết** về cấu trúc hiện tại và kế hoạch migration
- **Chuẩn bị sẵn sàng** cho các bước triển khai tiếp theo

## Deliverables
1. Báo cáo cấu trúc hiện tại (danh sách services, công nghệ, dependencies)
2. Kế hoạch migration chi tiết
3. Danh sách các file cần di chuyển và cập nhật
4. Timeline triển khai từng bước
5. Checklist chuẩn bị môi trường

## Công nghệ sử dụng
- **Backend**: Spring Boot (Java), FastAPI (Python)
- **Frontend**: Next.js (React)
- **Database**: MongoDB Atlas
- **Cache**: Redis
- **Message Queue**: Kafka
- **Containerization**: Docker, Docker Compose
- **Cloud**: Google Cloud MCP Server

## Cấu trúc thư mục mục tiêu
```
backend/
├── api-gateway/                 # Next.js - Port 8000
├── user-management-service/     # Spring Boot - Port 8001
├── document-management-service/ # Spring Boot - Port 8002
└── ai-service/                 # FastAPI - Port 8003

frontend/
└── web-app/                    # Next.js - Port 3000
```
