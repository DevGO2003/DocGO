# Tái cấu trúc Backend Services

## Prompt
```
Bạn là AI chuyên về tái cấu trúc backend services. Nhiệm vụ của bạn:

**TRƯỚC KHI THỰC HIỆN:**
1. Chạy lệnh `/git-push` để commit và push code hiện tại
2. KHÔNG tạo nhánh mới, làm việc trên nhánh hiện tại

**NHIỆM VỤ CHÍNH:**
Tái cấu trúc cấu trúc backend services theo kiến trúc mới:

**Cấu trúc hiện tại:**
```
backend/
├── api-gateway-bff/          # API Gateway (Next.js)
├── authentication-identity-service/  # Auth service (Spring Boot)
├── contract-management-service/      # Contract service (Spring Boot)  
├── ai-processing-service/           # AI service (FastAPI)
└── file-storage-asset-service/      # File service (FastAPI)
```

**Cấu trúc mới cần đạt được:**
```
backend/
├── api-gateway/              # API Gateway (Next.js) - ĐỔI TÊN
├── user-management-service/  # User + Auth + Organization (Spring Boot) - GỘP VÀ ĐỔI TÊN
├── document-management-service/  # Document + File (Spring Boot) - GỘP VÀ ĐỔI TÊN  
└── ai-service/              # AI Processing (FastAPI) - ĐỔI TÊN
```

**CÁC THAY ĐỔI CẦN THỰC HIỆN:**

1. **Đổi tên thư mục:**
   - `api-gateway-bff` → `api-gateway`
   - `ai-processing-service` → `ai-service`

2. **Gộp services:**
   - Gộp `authentication-identity-service` + `contract-management-service` → `user-management-service`
   - Gộp `file-storage-asset-service` + một phần contract logic → `document-management-service`

3. **Cập nhật tên service và ID:**
   - `authentication-identity-service` → `user-management-service`
   - `contract-management-service` → `document-management-service`
   - `ai-processing-service` → `ai-service`
   - `api-gateway-bff` → `api-gateway`

4. **Cập nhật package/group ID:**
   - Java services: đổi groupId và artifactId theo tên mới
   - Python services: cập nhật tên service trong code

5. **Cập nhật port mapping:**
   - `api-gateway`: 8000
   - `user-management-service`: 8001  
   - `document-management-service`: 8002
   - `ai-service`: 8003

6. **Cập nhật dependencies và imports:**
   - Sửa tất cả references đến tên service cũ
   - Cập nhật API endpoints
   - Sửa Dockerfile và docker-compose references

**LƯU Ý QUAN TRỌNG:**
- KHÔNG đụng vào thư mục `.cursor/`
- Giữ nguyên cấu trúc code bên trong, chỉ đổi tên và gộp
- Đảm bảo tất cả imports và references được cập nhật
- Test để đảm bảo không có lỗi compilation

**THỰC HIỆN THEO THỨ TỰ:**
1. Đổi tên thư mục đơn giản trước
2. Gộp services phức tạp sau
3. Cập nhật tất cả references
4. Test và fix lỗi
```

## Mục đích
Tái cấu trúc backend services theo kiến trúc mới với 4 services chính thay vì 5 services hiện tại.

## Cách sử dụng
Copy nội dung prompt trên và paste vào chat AI để thực hiện tái cấu trúc backend services.
