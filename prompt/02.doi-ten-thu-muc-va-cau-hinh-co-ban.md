# Đổi tên thư mục và cấu hình cơ bản

## Prompt
```
Bạn là chuyên gia DevOps và cấu hình hệ thống. Nhiệm vụ: ĐỔI TÊN thư mục và cập nhật cấu hình cơ bản cho DocGO.

Bối cảnh:
- Dự án: DocGO (hệ thống quản lý tài liệu thông minh)
- Cấu trúc mới: 4 microservices (api-gateway, user-management-service, document-management-service, ai-service)
- Frontend: web-app (Next.js)

Yêu cầu thực hiện:
1) **ĐỔI TÊN THƯ MỤC** theo cấu trúc mới:
   - backend/api-gateway-bff → backend/api-gateway
   - backend/authentication-identity-service → backend/user-management-service
   - backend/contract-management-service → backend/document-management-service
   - backend/ai-processing-service → backend/ai-service
   - backend/file-storage-asset-service → (gộp vào document-management-service)
   - frontend/web_nextjs → frontend/web-app

2) **CẬP NHẬT CẤU HÌNH** cơ bản:
   - Đổi tên trong docker-compose.yml
   - Cập nhật README.md
   - Cập nhật package.json (nếu có)
   - Cập nhật pom.xml (nếu có)
   - Cập nhật Dockerfile

3) **CẬP NHẬT GROUP ID và ARTIFACT ID** (Java):
   - Group ID: com.devgo2003.docgo.{service-name}
   - Artifact ID: {service-name} (viết tắt)
   - Package structure: com.devgo2003.docgo.{service_name}

4) **CẬP NHẬT PORT MAPPING**:
   - api-gateway: 8000
   - user-management-service: 8001
   - document-management-service: 8002
   - ai-service: 8003
   - web-app: 3000

5) **BẢO VỆ** dữ liệu quan trọng:
   - Không xóa thư mục .cursor/
   - Không xóa thư mục .git/
   - Không xóa các file cấu hình quan trọng
   - Backup trước khi thực hiện

Đầu ra bắt buộc:
- **Danh sách** các thư mục cần đổi tên
- **Danh sách** các file cần cập nhật
- **Nội dung** cập nhật cho từng file
- **Thứ tự** thực hiện từng bước
- **Checklist** kiểm tra sau mỗi bước
- **KHÔNG thực hiện** bất kỳ thay đổi nào, chỉ lập kế hoạch chi tiết
```

## Mục đích
Đổi tên thư mục và cập nhật cấu hình cơ bản cho cấu trúc mới

## Cách sử dụng
Copy nội dung prompt trên và paste vào chat AI để lập kế hoạch đổi tên và cấu hình
