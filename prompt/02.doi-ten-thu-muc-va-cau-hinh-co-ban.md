# Prompt 02: Đổi tên thư mục và cấu hình cơ bản

## Mục tiêu
Thực hiện đổi tên thư mục và cấu hình cơ bản để chuẩn bị cho kiến trúc mới 4 microservices.

## Nhánh hiện tại: dev

## Yêu cầu thực hiện

### 1. Đổi tên thư mục backend services
- **api-gateway-bff** → **api-gateway**
- **authentication-identity-service** → **user-management-service** (sẽ gộp thêm organization management)
- **contract-management-service** → **document-management-service** (sẽ gộp thêm file storage)
- **ai-processing-service** → **ai-service**

### 2. Cập nhật cấu hình cơ bản

#### 2.1 Docker Compose
- Cập nhật `docker-compose.yml` với tên services mới
- Cập nhật port mapping theo cấu trúc mới:
  - `api-gateway`: 8000
  - `user-management-service`: 8001
  - `document-management-service`: 8002
  - `ai-service`: 8003
  - `web-app`: 3000

#### 2.2 Environment Variables
- Cập nhật file `.env` cho từng service
- Cập nhật database connections
- Cập nhật service discovery URLs
- Cập nhật API endpoints

#### 2.3 Package.json và pom.xml
- Cập nhật tên package trong `package.json` (Next.js services)
- Cập nhật `groupId` và `artifactId` trong `pom.xml` (Spring Boot services)
- Cập nhật dependencies và versions

### 3. Cập nhật cấu hình Spring Boot

#### 3.1 Application Properties
- Cập nhật `application.properties` cho user-management-service
- Cập nhật `application.properties` cho document-management-service
- Cập nhật database connections
- Cập nhật JWT configurations
- Cập nhật CORS settings

#### 3.2 Package Structure
- Cập nhật package names trong Java files
- Cập nhật import statements
- Cập nhật component scanning paths
- Cập nhật entity mappings

### 4. Cập nhật cấu hình FastAPI

#### 4.1 AI Service
- Cập nhật `main.py` với tên service mới
- Cập nhật `config.py` với environment variables
- Cập nhật API routes và tags
- Cập nhật CORS settings

### 5. Cập nhật cấu hình Next.js

#### 5.1 API Gateway
- Cập nhật `next.config.js`
- Cập nhật API routes
- Cập nhật service discovery URLs
- Cập nhật middleware configurations

#### 5.2 Web App
- Cập nhật `next.config.js`
- Cập nhật API client configurations
- Cập nhật environment variables
- Cập nhật build configurations

### 6. Cập nhật documentation
- Cập nhật README.md cho từng service
- Cập nhật API documentation
- Cập nhật deployment guides
- Cập nhật development setup guides

## Lưu ý quan trọng
- **Làm việc trên nhánh `dev`**
- **Backup code cũ** trước khi thay đổi
- **Test từng bước** để đảm bảo không break
- **Commit thường xuyên** với message rõ ràng
- **Cập nhật tất cả references** đến tên cũ

## Cấu trúc thư mục mục tiêu
```
backend/
├── api-gateway/                 # Next.js - Port 8000
│   ├── pages/
│   ├── components/
│   ├── lib/
│   ├── package.json
│   └── next.config.js
├── user-management-service/     # Spring Boot - Port 8001
│   ├── src/main/java/com/devgo2003/docgo/user_service/
│   ├── src/main/resources/
│   ├── pom.xml
│   └── Dockerfile
├── document-management-service/ # Spring Boot - Port 8002
│   ├── src/main/java/com/devgo2003/docgo/document_service/
│   ├── src/main/resources/
│   ├── pom.xml
│   └── Dockerfile
└── ai-service/                 # FastAPI - Port 8003
    ├── main.py
    ├── routers.py
    ├── config.py
    ├── requirements.txt
    └── Dockerfile

frontend/
└── web-app/                    # Next.js - Port 3000
    ├── src/
    ├── package.json
    ├── next.config.js
    └── Dockerfile
```

## Công nghệ sử dụng
- **Backend**: Spring Boot (Java), FastAPI (Python)
- **Frontend**: Next.js (React)
- **Database**: MongoDB Atlas
- **Cache**: Redis
- **Message Queue**: Kafka
- **Containerization**: Docker, Docker Compose
- **Cloud**: Google Cloud MCP Server
