# Tái cấu trúc Frontend

## Prompt
```
Bạn là AI chuyên về tái cấu trúc frontend applications. Nhiệm vụ của bạn:

**TRƯỚC KHI THỰC HIỆN:**
1. Chạy lệnh `/git-push` để commit và push code hiện tại
2. KHÔNG tạo nhánh mới, làm việc trên nhánh hiện tại

**NHIỆM VỤ CHÍNH:**
Tái cấu trúc cấu trúc frontend theo kiến trúc mới:

**Cấu trúc hiện tại:**
```
frontend/
├── web/                      # React app
└── web_nextjs/              # Next.js app
```

**Cấu trúc mới cần đạt được:**
```
frontend/
└── web-app/                 # Web Application (Next.js) - GỘP VÀ ĐỔI TÊN
```

**CÁC THAY ĐỔI CẦN THỰC HIỆN:**

1. **Gộp và đổi tên:**
   - Gộp `web/` + `web_nextjs/` → `web-app/`
   - Ưu tiên sử dụng code từ `web_nextjs/` (Next.js) làm base
   - Merge các components và features từ `web/` vào `web_nextjs/`

2. **Cập nhật cấu trúc:**
   - Di chuyển tất cả components từ `web/src/components/` vào `web_nextjs/src/components/`
   - Merge các hooks, services, types từ `web/` vào `web_nextjs/`
   - Cập nhật imports và references

3. **Cập nhật package.json:**
   - Sử dụng package.json từ `web_nextjs/`
   - Merge dependencies từ `web/package.json` nếu cần
   - Cập nhật scripts và configurations

4. **Cập nhật Dockerfile:**
   - Sử dụng Dockerfile từ `web_nextjs/`
   - Cập nhật build commands và port mapping

5. **Cập nhật environment:**
   - Merge env files từ cả hai projects
   - Cập nhật environment variables

6. **Cập nhật routing:**
   - Đảm bảo tất cả routes từ `web/` được migrate sang Next.js routing
   - Cập nhật API calls và service integrations

**LƯU Ý QUAN TRỌNG:**
- KHÔNG đụng vào thư mục `.cursor/`
- Ưu tiên Next.js architecture (App Router)
- Đảm bảo tất cả features từ React app được migrate
- Test để đảm bảo không có lỗi compilation
- Giữ nguyên styling và UI components

**THỰC HIỆN THEO THỨ TỰ:**
1. Backup code quan trọng từ `web/`
2. Merge components và features vào `web_nextjs/`
3. Cập nhật imports và references
4. Test và fix lỗi
5. Xóa thư mục `web/` cũ
6. Đổi tên `web_nextjs/` thành `web-app/`
```

## Mục đích
Gộp hai frontend applications thành một Next.js application duy nhất.

## Cách sử dụng
Copy nội dung prompt trên và paste vào chat AI để thực hiện tái cấu trúc frontend.
