# Cập nhật Docker Compose

## Prompt
```
Bạn là AI chuyên về Docker và containerization. Nhiệm vụ của bạn:

**TRƯỚC KHI THỰC HIỆN:**
1. Chạy lệnh `/git-push` để commit và push code hiện tại
2. KHÔNG tạo nhánh mới, làm việc trên nhánh hiện tại

**NHIỆM VỤ CHÍNH:**
Cập nhật file `docker-compose.yml` để phù hợp với cấu trúc mới:

**Cấu trúc cũ (5 services):**
```yaml
services:
  api-gateway-bff:          # Port 8000
  authentication-identity-service:  # Port 8001  
  contract-management-service:      # Port 8002
  ai-processing-service:           # Port 8004
  file-storage-service:           # Port 8005
```

**Cấu trúc mới (4 services):**
```yaml
services:
  api-gateway:              # Port 8000 - ĐỔI TÊN
  user-management-service:  # Port 8001 - GỘP AUTH + CONTRACT
  document-management-service: # Port 8002 - GỘP FILE + CONTRACT LOGIC
  ai-service:              # Port 8003 - ĐỔI TÊN
```

**CÁC THAY ĐỔI CẦN THỰC HIỆN:**

1. **Cập nhật service names:**
   - `api-gateway-bff` → `api-gateway`
   - `authentication-identity-service` → `user-management-service`
   - `contract-management-service` → `document-management-service`
   - `ai-processing-service` → `ai-service`
   - Xóa `file-storage-service` (đã gộp vào document-management)

2. **Cập nhật container names:**
   - `docgo-api-gateway-bff` → `docgo-api-gateway`
   - `docgo-authentication-identity-service` → `docgo-user-management-service`
   - `docgo-contract-management-service` → `docgo-document-management-service`
   - `docgo-ai-processing-service` → `docgo-ai-service`

3. **Cập nhật port mapping:**
   - `api-gateway`: 8000 (giữ nguyên)
   - `user-management-service`: 8001 (giữ nguyên)
   - `document-management-service`: 8002 (giữ nguyên)
   - `ai-service`: 8003 (thay đổi từ 8004)

4. **Cập nhật build contexts:**
   - `backend/api-gateway-bff` → `backend/api-gateway`
   - `backend/authentication-identity-service` → `backend/user-management-service`
   - `backend/contract-management-service` → `backend/document-management-service`
   - `backend/ai-processing-service` → `backend/ai-service`

5. **Cập nhật env files:**
   - Cập nhật đường dẫn đến env files theo cấu trúc mới
   - Merge env variables từ các services đã gộp

6. **Cập nhật volumes:**
   - Cập nhật volume mounts theo đường dẫn mới
   - Merge volumes từ các services đã gộp

7. **Cập nhật networks và dependencies:**
   - Cập nhật service dependencies
   - Đảm bảo network connectivity giữa các services

8. **Cập nhật environment variables:**
   - Cập nhật service URLs trong environment variables
   - Cập nhật database connections
   - Cập nhật API endpoints

**LƯU Ý QUAN TRỌNG:**
- KHÔNG đụng vào thư mục `.cursor/`
- Giữ nguyên infrastructure services (Redis, Kafka)
- Đảm bảo tất cả services có thể start được
- Test connectivity giữa các services
- Cập nhật health checks nếu cần

**THỰC HIỆN THEO THỨ TỰ:**
1. Cập nhật service definitions
2. Cập nhật build contexts và volumes
3. Cập nhật environment variables
4. Test docker-compose up
5. Fix lỗi nếu có
```

## Mục đích
Cập nhật Docker Compose để phù hợp với cấu trúc mới 4 services thay vì 5 services.

## Cách sử dụng
Copy nội dung prompt trên và paste vào chat AI để thực hiện cập nhật Docker Compose.
