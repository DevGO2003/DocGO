# Triển khai API Gateway và User Management Service

## Prompt
```
Bạn là chuyên gia phát triển microservices. Nhiệm vụ: TRIỂN KHAI API Gateway và User Management Service cho DocGO.

Bối cảnh:
- Dự án: DocGO (hệ thống quản lý tài liệu thông minh)
- Cấu trúc mới: 4 microservices
- Nhiệm vụ: Triển khai 2 services đầu tiên

Yêu cầu thực hiện:
1) **TRIỂN KHAI API GATEWAY** (backend/api-gateway):
   - Chuyển đổi từ api-gateway-bff
   - Cập nhật routing cho 4 microservices
   - Cập nhật middleware authentication
   - Cập nhật proxy configuration
   - Cập nhật Swagger documentation
   - Port: 8000

2) **TRIỂN KHAI USER MANAGEMENT SERVICE** (backend/user-management-service):
   - Chuyển đổi từ authentication-identity-service
   - Gộp thêm organization management
   - Cập nhật package structure: com.devgo2003.docgo.user_service
   - Cập nhật Group ID: com.devgo2003.docgo.user-management-service
   - Cập nhật Artifact ID: user-service
   - Port: 8001

3) **CẬP NHẬT API ENDPOINTS**:
   - Authentication: /api/v1/user-management-service/auth/*
   - User Management: /api/v1/user-management-service/users/*
   - Organization: /api/v1/user-management-service/organizations/*
   - Member Management: /api/v1/user-management-service/organizations/{id}/members/*

4) **CẬP NHẬT DATABASE SCHEMA**:
   - Users collection
   - Organizations collection
   - Organization_members collection
   - JWT token management

5) **CẬP NHẬT DOCKER COMPOSE**:
   - Service names mới
   - Port mapping
   - Environment variables
   - Dependencies

6) **BẢO VỆ** dữ liệu quan trọng:
   - Không xóa thư mục .cursor/
   - Không xóa thư mục .git/
   - Backup trước khi thực hiện

Đầu ra bắt buộc:
- **Danh sách** các file cần cập nhật
- **Nội dung** cập nhật cho từng file
- **Thứ tự** thực hiện từng bước
- **Checklist** kiểm tra sau mỗi bước
- **Rủi ro** và cách xử lý
- **KHÔNG thực hiện** bất kỳ thay đổi nào, chỉ lập kế hoạch chi tiết
```
