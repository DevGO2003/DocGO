# Prompt 03: Triển khai API Gateway và User Management Service

## Mục tiêu
Triển khai API Gateway (Next.js) và User Management Service (Spring Boot) với đầy đủ tính năng authentication, authorization, và organization management.

## Nhánh hiện tại: dev

## Yêu cầu thực hiện

### 1. API Gateway (Next.js) - Port 8000

#### 1.1 Cấu trúc cơ bản
- Tạo thư mục `backend/api-gateway/`
- Cấu hình Next.js với TypeScript
- Setup routing và middleware
- Cấu hình CORS và security headers

#### 1.2 API Routes
- **Authentication Routes**:
  - `POST /api/auth/login` - Đăng nhập
  - `POST /api/auth/logout` - Đăng xuất
  - `POST /api/auth/refresh` - Refresh token
  - `GET /api/auth/me` - Thông tin user hiện tại

- **User Management Routes**:
  - `GET /api/users` - Danh sách users
  - `POST /api/users` - Tạo user mới
  - `GET /api/users/:id` - Chi tiết user
  - `PUT /api/users/:id` - Cập nhật user
  - `DELETE /api/users/:id` - Xóa user

- **Organization Routes**:
  - `GET /api/organizations` - Danh sách organizations
  - `POST /api/organizations` - Tạo organization
  - `GET /api/organizations/:id` - Chi tiết organization
  - `PUT /api/organizations/:id` - Cập nhật organization
  - `DELETE /api/organizations/:id` - Xóa organization

#### 1.3 Proxy Routes
- Proxy requests đến các microservices khác
- Load balancing và failover
- Request/Response transformation
- Error handling và logging

#### 1.4 Middleware
- JWT authentication middleware
- Rate limiting
- Request logging
- Error handling
- CORS configuration

### 2. User Management Service (Spring Boot) - Port 8001

#### 2.1 Cấu trúc cơ bản
- Tạo thư mục `backend/user-management-service/`
- Cấu hình Spring Boot với Spring Security
- Setup JPA và MongoDB integration
- Cấu hình JWT và OAuth2

#### 2.2 Entities
- **User**: id, username, email, password, firstName, lastName, status, roles, organizationId
- **Organization**: id, name, description, status, createdAt, updatedAt
- **Role**: id, name, description, permissions
- **Permission**: id, name, resource, action
- **UserSession**: id, userId, token, expiresAt, status

#### 2.3 Controllers
- **AuthController**: Login, logout, refresh token
- **UserController**: CRUD operations cho users
- **OrganizationController**: CRUD operations cho organizations
- **RoleController**: CRUD operations cho roles
- **PermissionController**: CRUD operations cho permissions

#### 2.4 Services
- **AuthService**: Xử lý authentication logic
- **UserService**: Xử lý user business logic
- **OrganizationService**: Xử lý organization business logic
- **RoleService**: Xử lý role business logic
- **PermissionService**: Xử lý permission business logic

#### 2.5 Security Configuration
- JWT token generation và validation
- Password encoding (BCrypt)
- Role-based access control (RBAC)
- CORS configuration
- Security headers

#### 2.6 Database Integration
- MongoDB repositories
- Database migrations
- Indexing strategies
- Connection pooling

### 3. API Documentation
- Swagger/OpenAPI documentation
- API testing endpoints
- Postman collection
- API versioning

### 4. Testing
- Unit tests cho controllers và services
- Integration tests cho API endpoints
- Security tests cho authentication
- Performance tests

### 5. Monitoring và Logging
- Application logging
- Health check endpoints
- Metrics collection
- Error tracking

## Lưu ý quan trọng
- **Làm việc trên nhánh `dev`**
- **Tuân thủ RESTful API design**
