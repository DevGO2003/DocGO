# Gộp Contract vào Document Management Service

## Prompt
```
Bạn là AI chuyên về gộp và tái cấu trúc microservices. Nhiệm vụ của bạn:

**TRƯỚC KHI THỰC HIỆN:**
1. Chạy lệnh `/git-push` để commit và push code hiện tại
2. KHÔNG tạo nhánh mới, làm việc trên nhánh hiện tại

**NHIỆM VỤ CHÍNH:**
Gộp logic từ `contract-management-service` và `file-storage-asset-service` vào `document-management-service` mới:

**Cấu trúc hiện tại:**
```
backend/
├── contract-management-service/    # Spring Boot - Contract logic
├── file-storage-asset-service/     # FastAPI - File storage logic
└── authentication-identity-service/ # Spring Boot - Auth logic
```

**Cấu trúc mới cần đạt được:**
```
backend/
├── user-management-service/        # Spring Boot - Auth + User + Organization
└── document-management-service/    # Spring Boot - Document + File + Contract
```

**CÁC THAY ĐỔI CẦN THỰC HIỆN:**

1. **Tạo document-management-service mới:**
   - Copy toàn bộ code từ `contract-management-service/`
   - Đổi tên service: `contract-management-service` → `document-management-service`
   - Cập nhật package name: `com.devgo2003.docgo.contract_service` → `com.devgo2003.docgo.document_service`

2. **Gộp file storage logic:**
   - Migrate file storage logic từ `file-storage-asset-service/` (FastAPI) sang Spring Boot
   - Convert Python code sang Java Spring Boot
   - Gộp file upload/download endpoints vào document-management-service

3. **Cập nhật entities và models:**
   - Gộp Contract entities với File entities
   - Tạo relationship giữa Document và File
   - Cập nhật database schema

4. **Cập nhật controllers:**
   - Gộp ContractController với FileController
   - Tạo DocumentController mới
   - Cập nhật API endpoints:
     - `/api/v1/document-management-service/documents` (thay vì contracts)
     - `/api/v1/document-management-service/files`
     - `/api/v1/document-management-service/attachments`

5. **Cập nhật services:**
   - Gộp ContractService với FileService
   - Tạo DocumentService mới
   - Cập nhật business logic

6. **Cập nhật repositories:**
   - Gộp ContractRepository với FileRepository
   - Tạo DocumentRepository mới
   - Cập nhật database queries

7. **Cập nhật dependencies:**
   - Thêm file storage dependencies vào pom.xml
   - Cập nhật Spring Boot configuration
   - Cập nhật database connections

8. **Cập nhật API Gateway:**
   - Cập nhật service URLs
   - Cập nhật API endpoints
   - Cập nhật routing

**LƯU Ý QUAN TRỌNG:**
- KHÔNG đụng vào thư mục `.cursor/`
- Giữ nguyên database schema hiện tại
- Đảm bảo backward compatibility
- Test tất cả API endpoints
- Cập nhật documentation

**THỰC HIỆN THEO THỨ TỰ:**
1. Tạo document-management-service mới
2. Copy và convert code từ contract-management-service
3. Migrate file storage logic từ FastAPI sang Spring Boot
4. Cập nhật entities và relationships
5. Cập nhật controllers và services
6. Test và fix lỗi
7. Cập nhật API Gateway
8. Xóa services cũ
```

## Mục đích
Gộp contract management và file storage thành một document management service duy nhất.

## Cách sử dụng
Copy nội dung prompt trên và paste vào chat AI để thực hiện gộp services.
