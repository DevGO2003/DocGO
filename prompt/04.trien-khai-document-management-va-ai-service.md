# Triển khai Document Management và Automation Service

## Prompt
```
Bạn là chuyên gia phát triển microservices. Nhiệm vụ: TRIỂN KHAI Document Management Service và Automation Service cho DocGO.

Bối cảnh:
- Dự án: DocGO (hệ thống quản lý tài liệu thông minh)
- Nhánh hiện tại: dev
- Cấu trúc mới: 4 microservices
- Nhiệm vụ: Triển khai 2 services cuối cùng

Yêu cầu thực hiện:
1) **TRIỂN KHAI DOCUMENT MANAGEMENT SERVICE** (backend/document-management-service):
   - Merge contract-management-service + file-storage-asset-service
   - Implement document upload/download
   - Contract lifecycle management
   - File processing và validation
   - Version control cho documents
   - Port: 8002

2) **TRIỂN KHAI AUTOMATION SERVICE** (backend/automation-service):
   - Chuyển đổi từ ai-processing-service
   - Document analysis và OCR
   - Contract summarization
   - Risk assessment
   - Compliance checking
   - Port: 8003

3) **CẬP NHẬT CẤU HÌNH**:
   - Document Service: com.devgo2003.docgo.document-management-service
   - Automation Service: FastAPI với Python
   - Database: MongoDB với collections mới
   - File Storage: S3/Filebase integration
   - AI Integration: Gemini API

4) **TÍCH HỢP VÀ TESTING**:
   - Test document upload/download
   - Test contract processing
   - Test automation analysis
   - Test file validation
   - Verify port mapping

5) **CẬP NHẬT DOCUMENTATION**:
   - API documentation cho cả 2 services
   - Swagger UI configuration
   - README files
   - How to run guides

6) **HOÀN THIỆN HỆ THỐNG**:
   - Cập nhật docker-compose.yml
   - Test toàn bộ hệ thống
   - Verify 4 microservices hoạt động
   - Performance testing

Lưu ý:
- Merge code từ 2 services cũ một cách cẩn thận
- Đảm bảo không mất tính năng nào
- Test kỹ lưỡng trước khi commit
- Tuân thủ quy tắc API standards của DocGO
```

## Mục đích
Prompt này dành cho AI chat thứ tư để triển khai Document Management Service và Automation Service, hoàn thiện kiến trúc 4 microservices mới.

## Cách sử dụng
Copy nội dung prompt trên và paste vào chat AI để thực hiện triển khai 2 services cuối cùng.
