# Triển khai Document Management và AI Service

## Prompt
```
Bạn là chuyên gia phát triển microservices. Nhiệm vụ: TRIỂN KHAI Document Management Service và AI Service cho DocGO.

Bối cảnh:
- Dự án: DocGO (hệ thống quản lý tài liệu thông minh)
- Nhánh hiện tại: dev
- Cấu trúc mới: 4 microservices
- Nhiệm vụ: Triển khai 2 services cuối cùng

Yêu cầu thực hiện:
1) **TRIỂN KHAI DOCUMENT MANAGEMENT SERVICE** (backend/document-management-service):
   - Chuyển đổi từ contract-management-service
   - Gộp thêm file-storage-asset-service
   - Cập nhật package structure: com.devgo2003.docgo.document_service
   - Cập nhật Group ID: com.devgo2003.docgo.document-management-service
   - Cập nhật Artifact ID: document-service
   - Port: 8002

2) **TRIỂN KHAI AI SERVICE** (backend/ai-service):
   - Chuyển đổi từ ai-processing-service
   - Cập nhật package structure và dependencies
   - Cập nhật requirements.txt
   - Port: 8003

3) **CẬP NHẬT API ENDPOINTS**:
   - Document Management: /api/v1/document-management-service/documents/*
   - File Management: /api/v1/document-management-service/files/*
   - Document Workflow: /api/v1/document-management-service/documents/{id}/workflow/*
   - AI Processing: /api/v1/ai-service/extract, /api/v1/ai-service/summarize, etc.

4) **CẬP NHẬT DATABASE SCHEMA**:
   - Documents collection (thay vì contracts)
   - Files collection
   - Document_types collection
   - AI_jobs collection

5) **CẬP NHẬT FRONTEND** (frontend/web-app):
   - Chuyển đổi từ web_nextjs
   - Cập nhật API calls
   - Cập nhật routing
   - Cập nhật components

6) **CẬP NHẬT DOCKER COMPOSE**:
   - Service names mới
   - Port mapping
   - Environment variables
   - Dependencies

7) **BẢO VỆ** dữ liệu quan trọng:
   - Không xóa thư mục .cursor/
   - Không xóa thư mục .git/
   - Backup trước khi thực hiện

Đầu ra bắt buộc:
- **Danh sách** các file cần cập nhật
- **Nội dung** cập nhật cho từng file
- **Thứ tự** thực hiện từng bước
- **Checklist** kiểm tra sau mỗi bước
- **Rủi ro** và cách xử lý
- **KHÔNG thực hiện** bất kỳ thay đổi nào, chỉ lập kế hoạch chi tiết
```

## Mục đích
Triển khai Document Management Service và AI Service với cấu trúc mới

## Cách sử dụng
Copy nội dung prompt trên và paste vào chat AI để lập kế hoạch triển khai 2 services cuối cùng

**Lưu ý quan trọng:**
- Đang làm việc trên nhánh `dev`
- Tất cả thay đổi sẽ được thực hiện trên nhánh `dev`
- Không ảnh hưởng đến nhánh `vibe-coding` hoặc `main`
