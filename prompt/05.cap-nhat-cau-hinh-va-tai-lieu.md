## Cấu trúc mới cần cập nhật

### Services (4 microservices)
```
api-gateway                 # Next.js - Port 8000
user-management-service     # Spring Boot - Port 8001
document-management-service # Spring Boot - Port 8002
automation-service         # FastAPI - Port 8003
web-app                    # Next.js - Port 3000
```

### Port Mapping
```
8000 - API Gateway
8001 - User Management Service
8002 - Document Management Service
8003 - Automation Service
3000 - Web App (Frontend)
```

### Group ID và Artifact ID
```
com.devgo2003.docgo.user-management-service
com.devgo2003.docgo.document-management-service
```

- **Backend**: Spring Boot (Java), FastAPI (Python)

- **Database**: MongoDB Atlas
- **Cache**: Redis
- **Message Queue**: Kafka
- **Containerization**: Docker, Docker Compose
- **Cloud**: Google Cloud MCP Server

## Lệnh test
```bash
# Test Docker Compose
docker compose -f docker-compose.yml up -d

# Test từng service
docker compose -f docker-compose.yml logs api-gateway
docker compose -f docker-compose.yml logs user-management-service
docker compose -f docker-compose.yml logs document-management-service
docker compose -f docker-compose.yml logs automation-service

# Test API endpoints
curl http://localhost:8000/api/health
curl http://localhost:8001/api/v1/health
curl http://localhost:8002/api/v1/health
curl http://localhost:8003/api/v1/health
```
