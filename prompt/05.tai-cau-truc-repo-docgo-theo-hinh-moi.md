# Tái cấu trúc repo DocGO theo hình mới

## Prompt
```
Bạn là một chuyên gia DevOps và Full-stack Developer với kinh nghiệm sâu về microservices architecture. Nhiệm vụ của bạn là tái cấu trúc toàn bộ repository DocGO theo cấu trúc mới được mô tả trong hình.

## Yêu cầu thực hiện:

### 1. Chuẩn bị trước khi thực hiện
- Chạy lệnh git push để backup code hiện tại: `git add . && git commit -m "Backup before restructure" && git push`
- KHÔNG tạo nhánh mới, làm việc trực tiếp trên nhánh hiện tại
- Đảm bảo không động vào các thư mục .cursor và các file cấu hình Cursor

### 2. Tái cấu trúc thư mục theo hình mới
Từ cấu trúc hiện tại:
```
DocGO/
├── backend/
│   ├── api-gateway-bff/
│   ├── authentication-identity-service/
│   ├── contract-management-service/
│   ├── ai-processing-service/
│   └── file-storage-asset-service/
├── frontend/
│   ├── web/
│   └── web_nextjs/
└── documents/
```

Chuyển thành cấu trúc mới:
```
DocGO/
├── backend/
│   ├── api-gateway-bff/
│   ├── authentication-identity-service/
│   ├── document-management-service/ (gộp từ contract-management-service)
│   ├── ai-processing-service/
│   └── file-storage-asset-service/
├── frontend/
│   ├── web/
│   └── web_nextjs/
└── documents/
```

### 3. Gộp contract-management-service vào document-management-service
- Copy toàn bộ nội dung từ `backend/contract-management-service/` vào `backend/document-management-service/`
- Cập nhật tất cả tên service từ "contract-management-service" thành "document-management-service"
- Cập nhật package names, group IDs, và artifact IDs trong Java
- Cập nhật tất cả references trong code
- Xóa thư mục `backend/contract-management-service/` sau khi copy xong

### 4. Cập nhật tên dự án và service IDs
Thay đổi tên dự án từ "DocGO" thành "DocumentGO" trong:
- Tất cả file README.md
- Tất cả file package.json (nếu có)
- Tất cả file pom.xml
- Tất cả file docker-compose.yml
- Tất cả file cấu hình khác

### 5. Cập nhật Docker Compose
- Sửa file `docker-compose.yml` để:
  - Thay đổi tên service từ `contract-management-service` thành `document-management-service`
  - Cập nhật tất cả references trong docker-compose
  - Đảm bảo port mapping vẫn hoạt động đúng
  - Cập nhật environment variables và volume mounts

### 6. Cập nhật API Gateway BFF
- Sửa tất cả references từ "contract-management-service" thành "document-management-service"
- Cập nhật service URLs và endpoints
- Cập nhật service discovery và routing

### 7. Cập nhật Frontend
- Sửa tất cả API calls từ contract service thành document service
- Cập nhật service URLs trong frontend code
- Cập nhật tên service trong UI components

### 8. Cập nhật tài liệu
- Sửa tất cả file README.md
- Cập nhật API documentation
- Cập nhật hướng dẫn cài đặt và chạy

### 9. Cập nhật cấu hình
- Sửa tất cả file .env và .env.example
- Cập nhật database connection strings
- Cập nhật service discovery configuration

### 10. Kiểm tra và xác nhận
- Đảm bảo tất cả services vẫn có thể build và chạy được
- Kiểm tra API endpoints hoạt động đúng
- Xác nhận frontend có thể kết nối với backend services
- Test toàn bộ hệ thống với docker-compose

## Lưu ý quan trọng:
- KHÔNG động vào thư mục .cursor và các file cấu hình Cursor
- KHÔNG tạo nhánh mới, làm việc trực tiếp trên nhánh hiện tại
- Backup code trước khi thực hiện bằng git push
- Đảm bảo tất cả thay đổi đều nhất quán và không bỏ sót
- Test kỹ lưỡng sau khi hoàn thành

## Kết quả mong đợi:
- Repository được tái cấu trúc hoàn toàn theo hình mới
- Tất cả services hoạt động bình thường
- Frontend kết nối được với backend
- Docker Compose chạy được toàn bộ hệ thống
- Tài liệu được cập nhật đầy đủ
```

## Mục đích
Tái cấu trúc toàn bộ repository DocGO theo cấu trúc mới, gộp contract-management-service vào document-management-service, và cập nhật tên dự án thành DocumentGO.
